## Управление таблицами

Консольная база данных, позволяющаю создавать, удалять и просматривать таблицы.
### Доступные команды

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец:тип> ...` | Создать новую таблицу с указанными столбцами |
| `drop_table <имя>` | Удалить существующую таблицу |
| `list_tables` | Вывести список всех созданных таблиц |
| `help` | Показать справку по командам |
| `exit` | Завершить работу программы |

При создании таблицы поддерживаются типы данных `int`, `str` и `bool`.

### Пример использования

Запуск приложения:

```bash
uv run database
```

Если пакет установлен как консольная программа или активировано виртуальное окружение:

```bash
database
```

Создание таблицы пользователей:

```text
create_table users name:str age:int active:bool
```

Просмотр списка таблиц:

```text
list_tables
```

Удаление таблицы:

```text
drop_table users
```

Вывод всех команд:

```text
help
```


Завершение работы:

```text
exit
```

Все изменения таблиц сохраняются в JSON-файле.
